**CS2 Helper** is a compact, fully standalone utility for convenient Counter-Strike 2 maintenance, Steam account management, config backups, and game cache cleaning.

---

## 🌟 Key Features

- 👤 **Steam Account Management**: Automatic detection of installed Steam, account scanning, and saving custom labels/names in the Windows Registry.
- 💾 **Config Backup**: Archiving the `remote` folder containing settings and binds into a single `.zip` file.
- 📂 **Quick Access**: Instant navigation to the `CFG` folder, the root `userdata` directory, and the demos folder.
- 🎬 **Demo Manager (`.dem`)**: View a list of all demos and their file sizes, delete outdated files, and quickly open the target folder.
- 🧹 **Cache Cleaning**: Removal of downloaded Steam Workshop maps and shader cache (App ID 730) with precise calculation of freed disk space.
- 🌐 **Bilingual Interface**: Full support for Russian and English languages.
- 🎨 **Modern UI**: Windows 11-style dark theme using the *Segoe UI* font and safe tooltips.

---

## 🛠️ Technologies

- **Python 3.x**
- **CustomTkinter** (Modern graphical user interface)
- **Winreg** (Secure user data storage in the Windows Registry)
- **PyInstaller** (Building a standalone `.exe` file)

---

## 🌟 Основные возможности

- 👤 **Управление аккаунтами Steam**: Автоматическое определение установленного Steam, сканирование аккаунтов и сохранение кастомных меток/имен в реестре Windows.
- 💾 **Резервное копирование конфигов**: Архивация папки `remote` с настройками и биндами в один `.zip` файл.
- 📂 **Быстрый доступ**: Мгновенный переход к папке `CFG`, корневой директории `userdata` и папке с демо-записями.
- 🎬 **Менеджер демо-записей (`.dem`)**: Просмотр списка всех демок, их размера, удаление устаревших файлов и быстрый переход к папке.
- 🧹 **Очистка кэша**: Удаление скачанных карт из Мастерской и кэша шейдеров (App ID 730) с точным подсчетом освобожденного места на диске.
- 🌐 **Двуязычный интерфейс**: Полная поддержка русского и английского языков.
- 🎨 **Современный UI**: Тёмная тема в стиле Windows 11 с использованием шрифта *Segoe UI* и безопасными тултипами.
